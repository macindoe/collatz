## Notation

As on comb.md: a state `(ω,d)` has peak `A = 3^d ω − 1 = 2^s y`, `s = v₂(A)`, `y` the exit; `state(y)` is door recovery; `node(y,s)` is the state at branch `s` on door `y`. Negative states have `ω < 0`; residues mod `3` are in `{0,1,2}`.

## Item A — the signed rules, derived

**Where a sign could enter, and why it does not.** (1) The exact division `y = A/2^s`: `A ≠ 0` (for `ω < 0`, `3^d ω ≤ −3`, so `A ≤ −4`), `s = v₂(|A|)` is finite, and `2^s | A` on either sign; `y` is the odd part of `A` with `A`'s sign. In Python, floor division is exact when the divisor divides the dividend, on either sign; the script asserts `a % b == 0` at every division. In JavaScript BigInt, `/` truncates and `>>` floors, both exact when the divisor divides; the page's `exactDiv` throws otherwise. (2) The recovery of `Ω`: `y + 1 ≠ 0` for `y ≠ −1` has finite `v₂`, `v₃` and an odd cofactor prime to `3` of its own sign. (3) The residue convention: `2^s y ≡ 2 (mod 3)` is a congruence; Python's `%` returns `{0,1,2}` on negatives (`−5 % 3 == 1`), JavaScript's BigInt `%` keeps the dividend's sign (`−5n % 3n === −2n`), so the page uses `mod3(n) = ((n % 3n) + 3n) % 3n`. That was the one place a sign would have entered the explorer silently.

**The predecessor rule 14.1.1.** `F(ω,d) = (Ω,D)` iff the exit `y` is a door `y_a` of `(Ω,D)` — door recovery is a bijection between odd integers `≠ −1` and (state, door index), and `−1` is no door (`2^{D−a} 3^a Ω = 0` is impossible). Given a live door and admissible `s`, `N = 2^s y + 1` is odd, nonzero, `≡ 0 (mod 3)`, and `(N/3^{v₃(N)}, v₃(N))` is a valid state of the sign of `y` with numerator `2^s y`. No sign is read. Mortality 14.5.1, Gardens of Eden 14.5.2, the cascade step 14.10.1, and the comb rules 18.2.1 / 18.2.3 are congruences and identities. `(−1,1)` is a Garden of Eden (`D = 1`, `Ω = −1 ≡ 2`): no state has `F`-image `(−1,1)`.

**The table.** `−5 + 1 = −4 = 2^2·(−1)` and `−7 + 1 = −6 = 2·3·(−1)` give `(−1,2)` with doors `−5` (`a = 0`) and `−7` (`a = 1`); `A(−1,2) = −10 = 2·(−5)`, so `F(−1,2) = (−1,2)`. `A(−1,4) = −82 = 2·(−41)`, `−41 + 1 = −40 = 2^3·(−5)` → `(−5,3)`; `A(−5,3) = −136 = 2^3·(−17)`, `−17 + 1 = −16 = 2^4·(−1)` → `(−1,4)`. The seven odd values of the classical cycle are the seven doors of the two states. `−3 + 1 = −2` → `(−1,1)`, `A(−1,1) = −4 = 2^2·(−1)`, exit `−1`.

**CORRECTION to the brief.** "A state whose exit is `−1` has no `F`-image — precisely `(−1,1)`" is wrong as stated. The exit is `−1` iff `3^d ω = 1 − 2^s`, iff `(ω,d) = node(−1, s)` for an even `s` — the whole chain on door `−1`: `(−1,1)` at `s = 2`, `(−5,1)` at `s = 4` (`A = −16`), `(−7,2)` at `6`, `(−85,1)` at `8`, `(−341,1)` at `10`, …, with `d = 1 + v₃(s)` (Lemma 14.2.1's `y = −1` case). Every one of them has no `F`-image. Among nodes with `s ≤ 2` — the ones whose parent would be a door edge — `(−1,1)` is the only one; that is the statement the comb needs (the singular root is the only node without a parent), and the page states both. Verified: the box `|ω| < 10^5`, `d ≤ 30` contains `9` states with exit `−1`, exactly door `−1`'s chain at branches `2..18`.

## Item B — the rings and the tree property, derived

**Lemma 18.8.2.1.** From a cycle node `v_i` at branch `s_i` on its exit door `y^{(i)}`: `⌊(s_i − 1)/2⌋` cascade edges down to the lowest sibling, then the door edge to `state(y^{(i)}) = F(v_i) = v_{i+1}` (18.2.2(b), the door parent defined because `v_{i+1}` exists). So the parent map on `{v_i} ∪ {lower siblings of v_i on y^{(i)}}` is a cyclic permutation of `Σ(1 + ⌊(s_i − 1)/2⌋)` nodes. Distinctness: different doors carry disjoint node sets; on one door nodes differ by branch; a cycle node `v_j` on door `y^{(i)}` has `v_{j+1} = state(y^{(i)}) = v_{i+1}`, so `j = i`. When `p = 1` and `s = 1` the door edge is the self-loop, excluded, and the ring is a single node with no parent (the positive root; `(−1,2)`). Conversely a cycle of the parent map contains a door edge (cascade edges lower the branch), and successive door-edge targets satisfy `t_{k+1} = F(t_k)` because all siblings on a door share `F`; so they are `F`-periodic and the cycle is their ring. Hence the parent map's cycles are exactly the rings of `F`-cycles.

Applied: `(1,1)`: `1`. `(−1,2)`: `1`. The 2-cycle: `s(−1,4) = 1`, `s(−5,3) = 3`, so `(1 + 0) + (1 + 1) = 3`, the third node being `node(−17, 1) = (−11,1)` (`2·(−17) + 1 = −33 = 3·(−11)`), whose `A = −34 = 2·(−17)` gives the door edge back to `(−1,4)`. Confirmed by direct computation and in the script's canaries.

**The tree property.** Every negative state except `(−1,1)` has one parent; the parent map's only cycles are rings; so from any non-ring node the chain repeats no node until it enters a ring or stops at `(−1,1)`. Within a component (the states whose chain reaches a given ring) the non-ring nodes therefore form a tree onto the ring. The chain visits `F(v), F²(v), …` in order with the cascade siblings between (18.2.2(c)'s argument), so it reaches the ring iff the `F`-orbit reaches the `F`-cycle — it may enter at a lower sibling of a cycle node one `F`-step early — and it reaches `(−1,1)` iff some `F`-iterate has exit `−1`. Verified on all `999,990` states of the box: chain target `=` orbit target at every state.

**The root degrees.** `(−1,1)`: door `−3` dead; cascade child `node(−1, 4) = (−5,1)`; degree `1`. `(−1,2)`: door `−5` gives itself (excluded), door `−7` gives `(−1,3)`, cascade child `node(−5, 3) = (−13,1)`; degree `2`. `(−1,4)`: doors `−17, −25, −37, −55` give `(−11,1)` [ring], `(−11,2)`, `(−49,1)`, `(−73,1)`; cascade child `node(−41, 3) = (−109,1)`. `(−5,3)`: doors `−41, −61, −91` give `(−1,4)` [ring], `(−1,5)`, `(−121,1)`; cascade child `node(−17, 5) = (−181,1)`. `(−11,1)`: door `−23` gives `(−5,2)`; cascade child `node(−17, 3) = (−5,3)` [ring]. All as the brief lists them (the brief did not name `(−5,2)`; it is `(−11,1)`'s one non-ring child).

**ADDITION, not in the brief: the distance relation on the negative components.** With `η` = `F`-steps to the `F`-cycle (to the first exit `−1` on the singular component) and `λ` = level, `η = door edges + ε`, `ε ∈ {0,1}`. Each `F`-step `v_i → v_{i+1}` is represented on the path by the door edge into `v_{i+1}` unless the chain has already stopped at the ring; it stops (i) during `v_i`'s cascade run, at a ring node that is a sibling below `v_i` — then `v_{i+1} = F(v_i)` is a cycle node and the last `F`-step has no edge, `ε = 1`; (ii) by a door edge into a ring node that is not `F`-periodic (`(−11,1)`) — one `F`-step remains, `ε = 1`; (iii) at the excluded self-loop — `ε = 1` (the positive comb's `+1` and `(−1,2)` entered through door `−5`); (iv) by a door edge into an `F`-periodic ring node — `ε = 0`. On the singular component the terminal cascade run down door `−1` stands for no `F`-step and `ε = 0` always. So `ε = 0` iff the last edge is a door edge into an `F`-periodic ring node (and always on the singular component). Proposition 18.3.2(b) is the positive case, where (iv) never occurs because the only door edge into `(1,1)` is the self-loop. Verified at every state of the box (`ε = 0` at `893,136`, `1` at `106,849`) and used by the explorer to fill `η` on the tree (`epsOf`), with `η` by `F`-iteration as the check.

## Item C — the census, and the largest-peak law

**Lemma 18.8.3.1.** For `ω < 0`, `|A| = 3^d|ω| + 1`; the doors have `|y_a| = 2^{D−a}3^a|Ω| + 1`, largest at `a = D − 1`, `|y_{D−1}| = 2·3^{D−1}|Ω| + 1 = (2|A| + 1)/3`. A door child's `|peak|` is `2^{s₀}|y_a| ≤ 4(2|A| + 1)/3 = (8|A| + 4)/3 < 4|A|` since `|A| ≥ 4`; the cascade child's is `4|A|`. So the level maximum quadruples and is attained only by the cascade child of the previous maximum. From the ring: singular `|A(−1,1)| = 4`, so `2^{2λ+2}` on door `−1` at branch `2λ + 2` — the brief's "`−(2^{2λ+2} …)`", confirmed; fixed `|A(−1,2)| = 10`, so `5·2^{2λ+1}` on door `−5`; 2-cycle: the level-`0` maximum is `|A(−5,3)| = 136`, whose cascade child `(−181,1)` is not a ring node, so `17·2^{2λ+3}` on door `−17` at branch `2λ + 3`. Verified at every level `0..20` of every component, with uniqueness of the argmax.

**The census.** Level counts to `20`: `991,425` (positive, equal to 18.5 row for row), `1,002,571`, `1,816,599`, `6,269,061` nodes. Ratios to the positive count at level `20`: `1.011`, `1.831`, `6.319`, constant from about level `15`. Per level, the mean depth, dead-top fraction, mean degree, level ratio and depth distribution are the positive comb's within sampling error (page table). The run-length table reproduces 18.5's census/ledger deviation on each component and the negative box matches the ledger at every printed entry. The digit-transfer law holds on `5,000` negative door edges with the same filtered-draw count pattern (`403`, all at `j = 1`). Nothing beyond the ring and the first levels differs; **no statistic disagreed**.

**The size census** (`−10^6 ≤ x ≤ −3`, `499,999` odd integers): `163,485 / 162,122 / 174,392` to `−1` / the `−5` cycle / the `−17` cycle, none elsewhere. The pre-check's counts for `(−2·10^5, −1)` — `32,880 / 32,172 / 34,947` — are reproduced exactly. A measurement; the negative conjecture is stated as open on the page.

## Item D — the fixed-state equation, derived

A state is `F`-fixed iff `state(y) = (ω,d)` iff `y` is a door of `(ω,d)`. At `s = 1`, `y = A/2 = (3^d ω − 1)/2`, and `y = y_a = 2^{d−a}3^a ω − 1` iff `3^d ω − 1 = 2^{d−a+1}3^a ω − 2` iff `ω·3^a·(2^{d−a+1} − 3^{d−a}) = 1` — the identity `2y_a − A = ω 3^a (2^{d−a+1} − 3^{d−a}) − 1`. At `a ≥ 1` the product is `≡ 0 (mod 3)`; at `a = 0`, `ω(2^{d+1} − 3^d) = 1` forces `2^{d+1} − 3^d = ±1 = ω`: `d = 1` gives `ω = 1`, `d = 2` gives `ω = −1`; `|2^a − 3^b| = 1` has no other solution with `a = b + 1` (Gersonides, cycles.md 12.6.1.2; checked as an identity for `d ≤ 60`). The sign of the state is the sign of `2^{d+1} − 3^d`. Stopped there, per the brief: no `s ≥ 2`, no longer period, no search.
