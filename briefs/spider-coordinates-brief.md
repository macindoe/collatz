**What the analogy asks for, stated so the answer is checkable.** A reduced state `(ω, d)` does two things for an odd integer `x`: it is read *off* `x` by two valuations (`x + 1 = 2^m 3^a ω`, `d = m + a`) with no iteration, and it lists *all* `d` odd integers it stands for by one closed formula (`y_a = 2^{d−a}3^aω − 1`, `0 ≤ a < d`). The question for a spider splits the same way: (i) from the abdomen `(Ω, D)`, is every member given by a closed formula in `(Ω, D)` and a position? (ii) from a member, is `(Ω, D)` read off without the walk? Items A–C answer (i) positively and exactly; Items B and E answer (ii): the descent is the Collatz map itself in two-halving steps, and the search for a walk-free identifier is expected to close negative with the reason stated, in the manner of 19.3's child-spider answer. Both halves go into the page, flat.

## Item A — the legs are the doors of `(Ω, D+1)` (a lemma; restates 19.1.6)

For an abdomen `(Ω, D)` write `t = v₃(2^{D+1}Ω − 1)` and write `y_b(Ω, D+1) = 2^{D+1−b}3^bΩ − 1`, `0 ≤ b ≤ D`, for the doors of the state one depth up on the same core.

**Claims to prove, from 18.2.3, 18.9.1 and 14.10.1.**

1. The **lower children** of `(Ω, D)` — the door-`a` children for `a = 1, …, D−1` and the cascade child — have numerators `3·y_b(Ω, D+1)` for `b = 0, …, D−1`, each door of `(Ω, D+1)` below the top once: the door-`a` child (branch `2`, always) has numerator `4y_a(Ω,D) + 1 = 3·y_{a−1}(Ω, D+1)`, and the cascade child has numerator `4A + 1 = 4·3^DΩ − 3 = 3·y_{D−1}(Ω, D+1)`. This holds at `D = 1` too, where the only lower child is the cascade child, numerator `3·y_0(Ω, 2) = 3(4Ω − 1)`.
2. The **top door** `y_0(Ω, D)` is alive iff `t ≥ 1`, and when alive its branch is always `s₀ = 1` (`y_0(Ω,D) ≡ 2 (mod 3)` is impossible: it would need `3 | 2^DΩ`), with numerator `2y_0(Ω,D) + 1 = 2^{D+1}Ω − 1 = y_0(Ω, D+1)`. So the door-`1` child and the top-door child share the core `y_0(Ω, D+1)/3^t`, at depths `t + 1` and `t` — Lemma 19.1.3's shared core, now at every `D ≥ 1` (at `D = 1` the "door-`1` child" is the cascade child).
3. Consequently the **legs** of `(Ω, D)` are exactly `(y_b(Ω, D+1), 1)` for `b = 1, …, D−1` (each `≡ 2 (mod 3)`: links, always) together with `(y_0(Ω, D+1)/3^t, 1)` when `t ≤ 1` (a fork when `t = 0`, class by residue when `t = 1`) — leg count `D − 1 + [t ≤ 1]`, the same count as 19.1.6 in one bracket; and a lower leg's core `x_0`, read as an odd integer, has `x_0 + 1 = 2^{D+1−b}3^bΩ`, i.e. `state(x_0) = (Ω, D+1)`: the lower legs' cores are the representatives of `(Ω, D+1)`, one depth above the abdomen on its own core.

**Pre-checked** (main session, throwaway): `2,003` random abdomens (`Ω < 10^6`, `2 ≤ D ≤ 12`), the leg set against claim 3 exactly, and claim 2's shared numerator asserted at every one; `0` failures. Canaries: `(1,2)` has `t = 0`, legs `(11,1) = (y_1(1,3), 1)` and `(7,1) = (y_0(1,3), 1)`, matching spiders.md's spider of `(1,2)`; `(5,2)` has `t = 1`, legs `(59,1) = (y_1(5,3), 1)` and `(13,1) = (y_0(5,3)/3, 1)`, with the door-`1` child `(13, 2)` and the top-door child `(13, 1)` sharing the core `13`.

## Item B — the hair descent map (a lemma)

For a depth-`1` node `(x, 1)` whose comb parent is depth-`1` (Lemma 19.1.5: `x ≡ 1, 17, 19 (mod 24)`), the parent is `(P(x), 1)` with

```text
P(x) = (3x + 1)/4   if x ≡ 1 (mod 8)   (the door parent at s = 1; x ≡ 1 or 17 mod 24)
P(x) = (x + 1)/4    if x ≡ 3 (mod 8)   (the cascade parent at s ≥ 3; x ≡ 19 mod 24)
```

(`x ≡ 5, 7 (mod 8)` give an abdomen parent, by 19.1.5's table.) In **raw coordinates** — the node's single representative `n = 2x − 1`, an odd integer `≡ 1 (mod 4)` with `3 ∤ (n+1)/2` — the same map is `n ↦ (3n + 1)/4` for `n ≡ 1 (mod 16)` and `n ↦ (n − 1)/4` for `n ≡ 5 (mod 16)`: the first is the Collatz map with exactly two halvings, the second is the inverse of the sibling relation `n ↦ 4n + 1`. **The owner of a depth-`1` node is found by iterating `P` while `x mod 24 ∈ {1, 17, 19}`, then taking the comb parent of the last node** (an abdomen, by 19.1.5) — that walk is the descent of a hair, and it is the Collatz map, restricted: say this plainly, since it is the honest core of the answer to (ii). Prove `P` from 18.2.1 and 19.1.5's proof (the three cases `s = 1, 2, ≥ 3` are already there); prove the raw form; state the continuation set in raw terms (`n mod 48 ∈ {1, 33, 37}`, derive it). **Pre-checked**: `13,293` random depth-`1` nodes (`x < 10^9`), the comb parent against `P` and the mod-`24` continuation test, `0` failures; the raw form on the same sample, `0` failures.

## Item C — the member formula and the lens identity (a proposition; the positive half of the answer)

Write a **hair word** `w = ε_1 ε_2 … ε_k ∈ {0,1}^k` for the steps up a hair from its leg `x_0`: `ε = 0` is a link step `x ↦ 4x − 1` (taken iff `x ≡ 2 (mod 3)`), `ε = 1` is a fork step `x ↦ (4x − 1)/3` (taken iff `x ≡ 1 (mod 3)` and `v₃(4x − 1) = 1`; the hair ends at a fork with `v₃(4x − 1) ≥ 2`). With `f_j = ε_1 + … + ε_j` (the number of fork steps so far):

```text
x_k = (4^k x_0 − c_w) / 3^{f_k},     c_w = Σ_{i=1}^{k} 4^{k−i} 3^{f_{i−1}}     (c_{wε} = 4c_w + 3^{f(w)}, c_∅ = 0)
```

so that `3^{f_k} x_k + c_w = 4^k x_0`. Adding `4^k` and using Item A.3:

```text
lower leg b ≥ 1:   3^{f} x + c_w + 4^k        = 4^k (x_0 + 1) = 2^{2k + D + 1 − b} 3^b Ω
top leg (t = 1):   3^{f+1} x + 3c_w + 4^k     = 4^k (3x_0 + 1) = 2^{2k + D + 1} Ω
```

**The lens identity:** the abdomen's core `Ω` is the `2,3`-free part of an affine image of the member, `3^f x + c_w + 4^k` (or its top-leg form), and `D` and `b` are its `2`-adic and `3`-adic valuations — exactly as `ω` is the `2,3`-free part of `x + 1` and `(d, a)` its valuations. The affine map (the **lens**) is fixed by the member's **position** `(b, w)`: `b` the leg's door index in `(Ω, D+1)`, `w` its hair word. So a spider member is addressed by `(Ω, D; b, w)` as a state's representative is addressed by `(ω, d; a)`, and the member is a closed formula in those four. Prove the recursion and both identities; state which `(b, w)` are admissible — the residue conditions on `x_0` along the word, hence (by Item A.3, `x_0 + 1 = 2^{D+1−b}3^bΩ`) on `Ω mod 3^{m}` with `m` growing by one per fork step and by none per link step (19.3's budget accounting), so that the set of admissible words of a spider is a function of `(D, Ω mod 3^{f+1+b})` or whatever the exact exponent is — derive it, do not guess. **Pre-checked**: `31,656` members enumerated from `2,000` random abdomens (`Ω < 10^5`, `2 ≤ D ≤ 8`) by walking every hair to its end, the lens identity at every member, `0` failures, hairs to length `34`. Canary: on the hair from the top leg `13` of `(5,2)`, the member `17` (word `w = 1`, `k = 1`, `f = 1`, `c_w = 1`) has `9·17 + 3 + 4 = 160 = 2^5 · 5`: `Ω = 5`, `2k + D + 1 = 5`.

**What the analogy gives and what it does not — one flat paragraph in the page.** (i) is answered: from `(Ω, D)` every member is a closed formula in the position. (ii) is not: reading `(b, w)` off a member is the descent of Item B, whose length is the hair position, unbounded by 19.2's law; a state's `(m, a)` are two valuations, a spider member's `(b, w)` are a Collatz orbit segment. That difference is 18.9's residue horizon in one more form, and the page says so without dressing it up.

## Item D — the raw dictionary of a spider (a remark, and one clause in `TOUR.md`)

Translate the spider into odd integers, using 18.4.1 and Item A.3: the abdomen is the rising run `y_0(Ω,D) → y_1 → … → y_{D−1}` (each step `(3n+1)/2`, one halving) followed by the exit `y` (`s + 1` halvings); the legs are the odd integers `2y_b(Ω, D+1) − 1` (`b ≥ 1`) and `2y_0(Ω,D+1)/3^t − 1` (`t ≤ 1`); a hair rises from a leg by the two moves `n ↦ 4n + 1` (when `3 | n`: a multiple of `3` has no odd Collatz preimage, and `4n + 1 ≡ 1 (mod 3)` is its sibling with the same image) and `n ↦ (4n − 1)/3` (when `n ≡ 1 (mod 3)`: the unique odd preimage with exactly two halvings), continuing while the result is depth `1` — derive the exact condition (a fork step ends the hair iff `n ≡ 4 (mod 9)`, or whatever the residue is). So in the classical Collatz graph a spider is **a maximal run of one-halving steps together with the two-halving predecessor chains that feed it, taken modulo the `4n + 1` sibling relation**. Verify the translation numerically (every member's raw value, every move) and put one clause into `TOUR.md`'s spider row; say what was checked for a literature name for this object (the `4n + 1` sibling relation is classical; predecessor chains by fixed halving count appear in the inverse-tree literature — check the record's own sources and `TOUR.md`'s citations, and report flat whether a name exists; no web access is needed or allowed).

## Item E — the search for a local invariant (measurements; answered either way)

The author's question, sharpened to something a search can close: **is there a function of a member, computable without the walk, that is constant on every spider and separates spiders?** Two searches over the full comb to level `18` (`247,932` nodes, `82,491` pieces; build it fresh), reported flat:

- **E.1, constancy of affine lenses.** For every candidate `g_{α,β}(x) = ` the `2,3`-free part of `αx + β`, over `α ∈ {1, 2, 3, 4, 6, 8, 9, 12, 16, 27}` and `β ∈ [−27, 27]` (skip the pairs where `αx + β` can vanish or is never positive), and for the comb quantities already on file — the node's exit `y`, its peak `A`, the peak's odd part, its top door `y_0`, `F(v)`, `F²(v)` — count the spiders (of size `≥ 2`) on which `g` is constant across all members, and separately across the members of each single hair, and across link-only stretches of hairs (where the exit `y` is invariant by construction: the control that must come out at `100%`). Report the table. The expectation is that nothing but the control is constant beyond chance level; if some `g` is constant on a large fraction of spiders, derive why before reporting it, and check whether it separates spiders (two spiders with equal `g` on all members).
- **E.2, residue determinacy of the position.** In the style of 18.9.3: for hair position `j = 1, 2, …` (the number of `P`-steps from the node to its leg), the least modulus `2^a 3^b` such that "the position is exactly `j`" is a function of `x mod 2^a 3^b` — search over small `(a, b)` exactly (full-coset test as 18.9.3 does), on all depth-`1` nodes of the census at that position; report the least modulus per `j` and its growth. Derive the expected growth from Item B (each `P`-step reads `x mod 8` and `mod 3`, and the fork steps consume ternary digits by 19.3's accounting) and compare. The same for the owner's `D` and for `Ω mod 3`, restricted to position `j`: report whether either is determined by a bounded residue at fixed `j` and how the modulus grows with `j`.

**The answer.** Expected: no walk-free identifier exists, for the reason Item B states — the walk is a Collatz orbit segment of unbounded length, so no bounded residue of a member decides its position, its owner's depth, or its owner's core, and no closed form for such a segment is on file or in the literature the record has already read (say exactly what was checked: `TOUR.md`'s dictionary rows and the sources it cites). If the searches say otherwise, the page says what they found and why. Either way, the page's answer to the author is Item C's coordinates `(Ω, D; b, w)` with the lens identity as the positive content, and Item E's closure as the calibration — not the type of the question.
