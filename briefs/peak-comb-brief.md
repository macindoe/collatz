## The object

**The peak.** For a state `(ω,d)` write `A(ω,d) = 3^d ω − 1 = 2^s y` (`s = v₂(A)`, `y` the exit, which is a door of `F(ω,d)`). Call `A` the **peak** of the state. Claims to prove: (i) `A` determines the state (`d = v₃(A+1)`, `ω = (A+1)/3^d`), so peaks and states are in bijection; (ii) an even integer is a peak iff `3 | A + 1`; (iii) along a door's cascade the even numbers `2y, 4y, 8y, …` alternate peak / non-peak, because `2^j y + 1 ≡ 0 (mod 3)` at every second `j` — the peaks on door `y` are exactly `2^s y` for `s` admissible in the sense of 14.1.1; (iv) the raw maximum of the block's trajectory is `2A`, one halving above the peak (spine.md §6.3: `3x_{m−1} + 1 = 2A`) — state this as a remark; the record's laws are written on `A`, so the peak is `A`.

**Worked instance (pre-checked by hand; re-verify):** door `5` carries the states `(7,1)`, `(1,4)`, `(107,1)` at branches `s = 2, 4, 6` with peaks `20, 80, 320`. The raw orbit from the entry of `(107,1)`, which is `213`, runs `640, 320, 160, 80, 40, 20, 10, 5`: it passes the peaks `80` and `20` and none of the odd points `15, 23, 35, 53` of `(1,4)` or `13` of `(7,1)`.

**The comb.** Nodes: the valid reduced states. Every node other than the root `(1,1)` has exactly one **comb parent**:

- if `s ≥ 3`: the **cascade parent**, the state at branch `s − 2` on the same door, `( (2^{s−2} y + 1) / 3^v, v )` with `v = v₃(2^{s−2} y + 1)` — always a valid state, since `2^{s−2} y ≡ 2^s y (mod 3)`; the edge is a **cascade edge**;
- if `s ≤ 2`: the **door parent**, `state(y) = F(ω,d)`; the edge is a **door edge**.

Equivalently, read upward: a node `(Ω,D)` has exactly one **cascade child** (the state at branch `s + 2` on its own door — reverse.md 14.10.1's `N(y, s+2) = 4N(y,s) − 3`, whose peak is `4A`) and one **door child** per live door (the state at the lowest admissible branch on that door, `s = 1` if `y ≡ 1 (mod 3)`, `s = 2` if `y ≡ 2 (mod 3)`). Claims to prove: (v) the parent rule is well defined and the resulting graph is a tree rooted at `(1,1)` — every node has exactly one parent, the root's own `s = 1` self-loop (door `1`, branch `1`) is the only exception and is excluded, and every node reaches the root by parents iff its `F`-orbit reaches `(1,1)` (so the comb's node set is exactly the backward tree of 14.4); (vi) **the root has exactly one child**, `(1,2)`, because the root's door `1` is its own cascade chain (branches `1, 3, 5, …` are `(1,1), (1,2), (11,1), (43,1), (19,3), …`) — the door child of door `1` at `s = 1` is the root itself; (vii) **every node has finite degree**: one cascade child plus one door child per live door, i.e. `D` or `D − 1` door children (the top door dead iff `2^D Ω ≡ 1 (mod 3)`, 14.5.1; side doors never dead), so every level is finite with no size cutoff — the infinite fan of 14.1.1 becomes a chain; (viii) along a cascade chain the peaks are `A, 4A, 16A, …` exactly.

**Two distances.** For a node, the **reduced distance** `r` is the number of `F`-steps to `(1,1)`; the **peak distance** `ℓ` is the number of comb edges to `(1,1)` (the level). Claims to prove: (ix) `r` equals the number of door edges on the comb path to the root, and `ℓ − r` the number of cascade edges; (x) all siblings on one door share `r` (each is one `F`-step from the door's state) and are separated by `ℓ`; (xi) `ℓ ≥ r`, with equality iff the path uses no cascade edge.

**Completeness against the raw map (the author's question, answered in the session; re-verify).** The comb accounts for every way into a state under the raw map: the odd numbers inside a block's rising run are the side doors (the top door's block visits every side door in turn: `T(y_a) = y_{a+1}`); the even numbers inside a cascade are the higher branches of the same door; the even number between two consecutive doors, `2 y_{a+1}`, has the in-block `y_a` as its only odd predecessor. So doors × admissible `s` is complete — that is 14.1.1's own theorem, and the comb only re-indexes it. Verify by brute force on a box: for every odd `x` below a bound, the odd predecessors of every integer on `x`'s raw trajectory up to its exit are exactly the comb neighbours predicted.

**The one family-frame law that survives.** ladder.md 15.6.2's mechanism is orbit-level: a depth-`1` node with core `≡ 1 (mod 2^j)`, `j ≥ 3`, has a door edge at `s = 1` to a depth-`1` node with core `≡ 1 (mod 2^{j−2})`, repeating until `j < 3`. Restate it in comb language (a forced chain of `⌊(j−1)/2⌋` door edges toward the root, all at `s = 1`, `m₊ = 1`) and verify it on the comb; do not re-prove it, cite 15.6.2.
