PART 3.  The proof's own steps, checked numerically
==============================================================================
   Step 1 (well-definedness).  f_r := gamma + (L-1)T_{r-1} - r - eta,
     cap_r = floor(f_r).  f_{r+1} - f_r = (L-1)cap_r - 1, so cap_r >= 2
     forces f nondecreasing, hence cap_{r+1} >= 2: gamma >= 2 + eta
     alone makes the greedy run to completion.  Checked: cap_r = floor(f_r)
     exactly (the big-integer cap agrees with the real formula), and
     cap_r >= 2 throughout whenever gamma >= 2 + eta.

   Step 2 (growth).  T_r > L T_{r-1} + gamma - r - beta, beta = 1 + eta,
     so T_r > A_r where A_r = L A_{r-1} + gamma - r - beta, A_{-1} = 0.

   Step 3 (closed form).  A_r = [L^{r+1}((gamma-beta)(L-1) - 1)
     + (r+beta-gamma)(L-1) + L] / (L-1)^2, and A_{p-2} >= n-1 is
     exactly gamma >= Gamma(p,n).

   Step 4 (landing).  T-hat_{p-2} >= n-1 forces the landing budget to
     bind, hence T_{p-2} = n-1 and crash depth exactly 1.

NC-A.  The quality hypothesis bites (perturb gamma downward)
==============================================================================
   At each p sweep n over a window at the canonical scale.  For each n
   record d(n) = gamma(n) - Gamma(p,n) and whether the construction's
   p exact size conditions all hold.  Two things are being tested:
     SOUNDNESS  every n with d >= 0 passes  (the theorem)
     BITE       some n in the window fails  (the hypothesis is not vacuous)
   d is used per-n, not against a single number, because Gamma depends
   on n through kappa = n/L^p and the window spans a range of kappa.
