PART 7 -- section-96 mechanism, RECONSTRUCTION not reproduction
==============================================================================

  The accelerated map: for odd x, one step is x -> (p*x+1) / 2^v, v =
  v_2(p*x+1) (the exact power of 2 making the quotient odd again). The
  claim under reconstruction: no multiplicative altitude V(x) = x*f(x mod
  2^k), fixed k, can be strictly decreasing at every step, for any f.

  THE TELESCOPING STEP, written out. Let g = log f. For large x (the p*x+1
  term dominating the +1), log V(x') - log V(x) ~= (log p - v*log 2) +
  [g(r') - g(r)], where r = x mod 2^k, r' = x' mod 2^k. Strict decrease at
  every step requires (log p - v_i*log 2) + g(r_{i+1}) - g(r_i) < 0 for
  every edge (r_i, v_i, r_{i+1}) of the RESIDUE graph (odd residues mod
  2^k, one outgoing edge per node: r -> (p*r+1)/2^v mod 2^k, using the
  small representative -- an operational convention, recorded as such
  below). Summing this inequality around any directed cycle r_1 -> r_2 ->
  ... -> r_L -> r_1 of that graph, the g(r_{i+1}) - g(r_i) terms telescope
  to exactly 0 (a closed sum around a cycle), leaving the NECESSARY,
  f-independent condition:

      Sum_{i=1}^{L} (log p - v_i * log 2)  <  0      i.e.      p^L < 2^K,
      K = Sum v_i.

  A residue cycle failing this (p^L >= 2^K, computed as an EXACT integer
  comparison below, no floating point) is called FAULTY: no choice of f
  can make V strictly decreasing along it -- the constraint set is
  unsatisfiable regardless of f.

  INTERPRETATION (recorded as a finding, not asserted as proved):
  for p=3, log2(3) is famously close to low-height rationals (the
  whole L-A9/cycles.md front is built on exactly this closeness),
  so p^L vs 2^K is a near-tie at small scale and 'faulty' status is
  fragile in k -- appearing and disappearing as k grows through
  different partial-quotient regimes of log2(3)'s own continued
  fraction (Part 4 above). For p=7, log2(7)=2.807 sits nowhere near
  such a tie, so faulty cycles appear immediately and robustly at
  k=8. This is a plausible mechanism for why the reconstruction
  reproduces cleanly at p=7 but not at small k for p=3 -- offered
  as an observation, not verified further in this session.

  GAPS RECORDED (operational definitions guessed, per the brief):
  1. Residue-graph transition uses the canonical small representat-
     ive only (r -> (p*r+1)/2^v mod 2^k); shown algebraically that
     this is NOT the same as the true quotient dynamics once v>0,
     since higher bits of an actual integer change the next
     residue. This is exactly why a 'faulty cycle' in the graph
     need not be realized by any actual integer -- it is the model
     the phantom/real distinction is built to probe, not an
     incidental limitation.
  2. 'Edge realizable' interpreted as: some actual integer reaches
     the designed target residue with the designed valuation --
     true by construction at m=0 for every edge, so this check
     (matching Merle's reported '20,000 random edges, all
     realised') is a tautological well-formedness confirmation,
     not independent evidence; recorded as such rather than as a
     substantive result.
  3. 'Phantom' is tested as: no actual integer x0 in a bounded
     search closes a genuine period-L orbit (X_L = X_0 exactly).
     A weaker test (the residue PATTERN merely recurring once
     along some real trajectory, without X_L = X_0) was considered
     and rejected as the criterion, because for a faulty cycle the
     real value grows by exactly the factor p^L/2^K > 1 that makes
     it faulty -- so a residue match at step L does not mean the
     integer returned, only that its residue class did.
  4. All searches are bounded (x0 up to a few million per cycle);
     'phantom' is reported relative to that bound, not as a proof
     of non-existence for all integers.
